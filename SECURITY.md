# Security

## Reporting a problem with the website

Report it privately through this repository's **Security** tab, **Report a vulnerability**. That covers anything on the site itself: a script that could be abused, a download link or checksum that does not match a release, a page that could be used to mislead a visitor, or a weakness in these workflows.

Please do not open a public issue for a security problem.

## Reporting a problem with VeilVoice itself

The program, its releases and its signing are in [tilas01/veilvoice](https://github.com/tilas01/veilvoice). Report those privately through that repository's Security tab, as its [security policy](https://github.com/tilas01/veilvoice/blob/main/docs/SECURITY.md) describes.

## What to expect

A reply within a few days, a fix as soon as it is understood, and credit in the notes if you want it.
